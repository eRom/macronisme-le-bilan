Déficit 2017 notifié à 2,9 % du PIB (premier passage sous 3 % depuis 2007), dette fin 2017 autour de 98 % (environ 2 220 Md€). Le Conseil de l'UE clôt la procédure de déficit excessif en juin 2018. Déficit 2018 : 2,3 % ; 2019 : environ 3,1 % dont un effet exceptionnel de la bascule CICE/cotisations (~0,9 point) ; dette fin 2019 : environ 97,4 % du PIB, quasi stable sur le premier quinquennat pré-Covid.

Grade B : les chiffres sont officiels (séries INSEE), mais les dates exactes de notification n'ont pas été re-vérifiées sur les communiqués d'époque. Précision de la date de fiche : au mois.
